Finds closest vehicle to incident, activates Green Corridor, and animates route.

📚 Data Structures & Algorithms Used

🗺️ Weighted Graph

Adjacency List representing intersections as vertices ($V$) and bidirectional roads as edges ($E$) with distance weights.

Class: RoadNetwork
⚡ Dijkstra's Algorithm

Min-Priority Queue based shortest path algorithm ($O((V+E)\log V)$) to calculate fastest route to emergency.

Class: ShortestPath
🚑 Singly Linked List

Dynamic vehicle registration, searching by number/type, insertion, and deletion with zero fixed-size limits.

Class: EmergencyVehicleList
🚦 FIFO Queue

First-In-First-Out waiting queue at traffic intersections. Front vehicle passes when signal turns green.

Class: TrafficQueue
📜 LIFO Stack

Last-In-First-Out audit log tracking all user and emergency operations in reverse chronological order.

Class: TrafficActionStack
🚨 Green Corridor

Dynamic traffic signal preemption that turns lights GREEN along the emergency route to prevent queue delays.

Class: TrafficSimulation
